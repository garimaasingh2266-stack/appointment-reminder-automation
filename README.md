# Appointment Reminder Automation for Local Businesses
Built in Make for salons, gyms and clinics to cut no-shows.

## What it does
Every morning, reads the appointment sheet in Google Sheets, finds clients booked for tomorrow who haven't been reminded yet, and sends each one a personalised reminder email.

## How it works
Google Sheets (search rows) → filter: tomorrow + not yet reminded → set variable → Gmail (send email)

## Built with
Make · Google Sheets · Gmail
